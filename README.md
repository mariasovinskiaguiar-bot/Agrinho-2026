# 🌱 AgroForte Tech 3D

Painel de monitoramento agrícola inteligente com interface moderna e efeitos visuais 3D em CSS. Centraliza dados cruciais para o gerenciamento da agricultura do futuro.

---

## ✨ Funcionalidades Principais

* **Design 3D:** Efeito de profundidade visual utilizando `perspective` e `rotateX` via CSS.
* **Cards Interativos:** Exibição sob demanda de métricas de Produção, Umidade, Máquinas e Sustentabilidade.
* **Alertas em Tempo Real:** Banner animado para avisos críticos (ex: instabilidade climática).
* **Interface Responsiva:** Adaptável para computadores, tablets e celulares.

---

## 🚀 Tecnologias

* **HTML5:** Estrutura semântica.
* **CSS3:** Animações (`@keyframes`), variáveis e estilização neon.
* **JavaScript:** Função nativa `toggle()` para exibição dinâmica dos dados.

---

## 🛠️ Como Executar

1. Baixe o código do projeto.
2. Abra o arquivo `.html` diretamente em qualquer navegador web.
